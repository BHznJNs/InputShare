# Atajos

Los siguientes atajos están disponibles después de la conexión:

| Atajo | Descripción |
| --- | --- |
| `<Ctrl>+<Alt>+s` | Alternar el control entre su ordenador y su dispositivo Android |
| `<Ctrl>+<Alt>+q` | Salir del programa |
| `F1` | Cambio de multitarea |
| `F2` | Volver a inicio |
| `F3` | Atrás |
| `F4` | Medios anteriores |
| `F5` | Reproducir / Pausar medios |
| `F6` | Medios siguientes |
| `F7` | Bajar volumen |
| `F8` | Subir volumen |
| `F9` | Bajar brillo |
| `F10` | Subir brillo |
| `F11` | Pantalla en reposo |
| `F12` | Despertar |
| Botón lateral del ratón `X1` | Atrás |
| Botón lateral del ratón `X2` | Abrir notificación |

Los siguientes atajos están disponibles después de la conexión y sin compartir:

| Atajo | Descripción |
| --- | --- |
| `<Alt>+UP` | Desplazarse hacia arriba |
| `<Alt>+DOWN` | Desplazarse hacia abajo |
| `<Alt>+[` | Medios anteriores |
| `<Alt>+]` | Medios siguientes |
| `<Alt>+\` | Reproducir / Pausar medios |
