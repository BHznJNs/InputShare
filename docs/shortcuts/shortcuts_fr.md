# Raccourcis

Les raccourcis suivants sont disponibles après connexion :

| Raccourci | Description |
| --- | --- |
| `<Ctrl>+<Alt>+s` | Basculer le contrôle entre votre ordinateur et votre appareil Android |
| `<Ctrl>+<Alt>+q` | Quitter le programme |
| `F1` | Commutation multitâche |
| `F2` | Retour à l'accueil |
| `F3` | Retour |
| `F4` | Média précédent |
| `F5` | Lecture / Pause média |
| `F6` | Média suivant |
| `F7` | Baisser le volume |
| `F8` | Augmenter le volume |
| `F9` | Baisser la luminosité |
| `F10` | Augmenter la luminosité |
| `F11` | Mise en veille de l'écran |
| `F12` | Réveil |
| Bouton latéral de la souris `X1` | Retour |
| Bouton latéral de la souris `X2` | Ouvrir la notification |

Les raccourcis suivants sont disponibles après connexion et sans partage :

| Raccourci | Description |
| --- | --- |
| `<Alt>+UP` | Faire défiler vers le haut |
| `<Alt>+DOWN` | Faire défiler vers le bas |
| `<Alt>+[` | Média précédent |
| `<Alt>+]` | Média suivant |
| `<Alt>+\` | Lecture / Pause média |
