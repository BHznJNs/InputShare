# Ярлыки

Следующие ярлыки доступны после подключения:

| Ярлык | Описание |
| --- | --- |
| `<Ctrl>+<Alt>+s` | Переключить управление между компьютером и устройством Android |
| `<Ctrl>+<Alt>+q` | Выйти из программы |
| `F1` | Переключение между задачами |
| `F2` | Вернуться на главный экран |
| `F3` | Назад |
| `F4` | Предыдущий медиафайл |
| `F5` | Воспроизведение / Пауза медиафайла |
| `F6` | Следующий медиафайл |
| `F7` | Уменьшить громкость |
| `F8` | Увеличить громкость |
| `F9` | Уменьшить яркость |
| `F10` | Увеличить яркость |
| `F11` | Спящий режим экрана |
| `F12` | Пробуждение |
| Боковая кнопка мыши `X1` | Назад |
| Боковая кнопка мыши `X2` | Открыть уведомление |

Следующие ярлыки доступны после подключения и без совместного использования:

| Ярлык | Описание |
| --- | --- |
| `<Alt>+UP` | Прокрутить вверх |
| `<Alt>+DOWN` | Прокрутить вниз |
| `<Alt>+[` | Предыдущий медиафайл |
| `<Alt>+]` | Следующий медиафайл |
| `<Alt>+\` | Воспроизведение / Пауза медиафайла |
