# よくある質問

## ワイヤレスデバッグを素早く有効にするには？

このビデオを参照して、ワイヤレスデバッグをクイック設定ショートカットに追加できます：
[How To Add / Remove Wireless Debugging Quick Setting Shortcut](https://www.youtube.com/watch?v=_MMpawUGeKI)

## Android デバイスの画面をコンピューターと共有しますか？

いいえ、__InputShare__はキーボードとマウスのみを共有し、Android デバイスの画面をコンピューターにミラーリングしません。

## デバイスを接続した後、FX ファンクションキーを使用できないのはなぜですか？

カスタマイズされた Android システム（例：MIUI または HyperOS）を使用している場合は、以下の手順を試してください：

1. デバイスで開発者向けオプションを開きます。
2. __USB デバッグ__と__USB デバッグ（セキュリティ設定）__を有効にします。

これらの設定を完了した後、ショートカットキーを再度使用してみてください。

## 「エッジトグル」を有効にした後、タブレットからエッジスワイプでコンピューターに戻れないのはなぜですか？

これは、タブレットに切り替えるときにマウスボタンを押し続けたことが原因かもしれません。ボタンを再度押してやり直してください。

## ADB を自分で構成する必要がありますか？

いいえ、組み込みの ADB がパッケージ化されており、自動的に呼び出されます。

## なぜ有線接続で接続に失敗することが多いのですか？

これは、有線接続を使用する際に、USB 構成で「充電のみ」を選択したことが原因かもしれません。このモードでは、一部の Android デバイスで有線 ADB 接続ができません。
