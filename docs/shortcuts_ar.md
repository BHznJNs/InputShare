# الاختصارات

الاختصارات التالية متاحة بعد الاتصال:

| الاختصار | الوصف |
| --- | --- |
| `<Ctrl>+<Alt>+s` | تبديل التحكم بين جهاز الكمبيوتر وجهاز Android الخاص بك |
| `<Ctrl>+<Alt>+q` | إنهاء البرنامج |
| `F1` | تبديل المهام المتعددة |
| `F2` | العودة إلى الشاشة الرئيسية |
| `F3` | رجوع |
| `F4` | الوسائط السابقة |
| `F5` | تشغيل / إيقاف مؤقت للوسائط |
| `F6` | الوسائط التالية |
| `F7` | خفض مستوى الصوت |
| `F8` | رفع مستوى الصوت |
| `F9` | خفض السطوع |
| `F10` | رفع السطوع |
| `F11` | وضع سكون الشاشة |
| `F12` | إيقاظ |
| زر الماوس الجانبي `X1` | رجوع |
| زر الماوس الجانبي `X2` | فتح الإشعار |

الاختصارات التالية متاحة بعد الاتصال وعدم المشاركة:

| الاختصار | الوصف |
| --- | --- |
| `<Alt>+UP` | التمرير لأعلى |
| `<Alt>+DOWN` | التمرير لأسفل |
| `<Alt>+[` | الوسائط السابقة |
| `<Alt>+]` | الوسائط التالية |
| `<Alt>+\` | تشغيل / إيقاف مؤقت للوسائط |
