# ショートカット

接続後に利用可能なショートカットは以下の通りです：

| ショートカット | 説明 |
| --- | --- |
| `<Ctrl>+<Alt>+s` | コンピューターと Android デバイス間の制御を切り替えます |
| `<Ctrl>+<Alt>+q` | プログラムを終了します |
| `F1` | マルチタスク切り替え |
| `F2` | ホームに戻る |
| `F3` | 戻る |
| `F4` | 前のメディア |
| `F5` | メディアの再生 / 一時停止 |
| `F6` | 次のメディア |
| `F7` | 音量を下げる |
| `F8` | 音量を上げる |
| `F9` | 輝度を下げる |
| `F10` | 輝度を上げる |
| `F11` | 画面スリープ |
| `F12` | ウェイクアップ |
| マウスサイドボタン `X1` | 戻る |
| マウスサイドボタン `X2` | 通知を開く |

接続後、共有していない場合に利用可能なショートカットは以下の通りです：

| ショートカット | 説明 |
| --- | --- |
| `<Alt>+UP` | 上にスクロール |
| `<Alt>+DOWN` | 下にスクロール |
| `<Alt>+[` | 前のメディア |
| `<Alt>+]` | 次のメディア |
| `<Alt>+\` | メディアの再生 / 一時停止 |
